도화당 · 문구 관리

수정한 내용은 Firebase에 저장되어 어떤 기기·브라우저에서 접속해도 홈페이지에 동일하게 반영됩니다. (네트워크 오류 시에는 이 브라우저에 마지막으로 불러온 내용이 임시로 표시됩니다.)

홈페이지 첫 화면

줄바꿈은 <br>을 사용할 수 있습니다.

업로드 후 저장하기를 눌러야 Firebase Storage에 올라가고 홈페이지에 반영됩니다. 비워두면 기존 background.png가 계속 사용됩니다.

홈페이지 첫 화면의 입력 카드(양력/음력 탭 바로 위) 상단에 표시되는 사진입니다. 비워두면 표시되지 않습니다.

분석 메뉴 제목 / 설명

각 사주 결과 화면의 섹션 제목과 설명을 수정합니다.

분석 카드 문구

비워두면 기존의 자동 생성 문구가 사용됩니다. 입력하면 해당 카드의 문구를 고정해서 표시합니다.
